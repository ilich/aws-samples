# AWS Samples

The repository contains a collection of AWS scripts, how-tos, and snippets that may simplify your life.

## Amazon ECR

* **migrate-repositories** - Shell script to pull Docker images from one AWS ECR registry and push them to another, preserving repository names and tags

## Amazon Textract

* **multi-page_pdf** - Use Amazon Textract to extract text content from the scanned handwritten text in a multi-page PDF file

## AWS Lambda

* **function_url** - Expose AWS Lambda though Function URL

## AWS Systems Manager (SSM)

* **bulk_parameters** - CLI tool to bulk export SSM Parameter Store parameters to a CSV file and bulk import them back
